# 품·단·복 고지 자동화

폰케이스 상품의 **품절 · 단종 · 복귀** 공지를 받아, 플랫폼 담당자에게 보낼 고지 엑셀과 고지 멘트를 한 번에 만드는 브라우저 툴입니다.

## 왜 만들었나

상품 공지가 오면 매번 같은 일을 손으로 반복했습니다.

1. 공지 텍스트(예: "판매중인 폰케이스 상품 중 단종 상품" + 상품명 / ID 목록)를 읽는다
2. NESS, NBOX 상품 파일에서 해당 상품을 찾아 고지용 엑셀을 따로 만든다
3. NESS, NBOX, 숲토어마다 형식이 다른 고지 멘트를 쓴다

플랫폼이 셋이고 공지 형태도 색상 한정 단종, 상품명·제조사 변경처럼 변칙이 많아 실수가 나기 쉬웠습니다.

## 하는 일

- 공지 텍스트를 붙여 넣으면 공지 종류와 대상 상품을 해석
- NESS, NBOX 상품 파일(엑셀/CSV)을 올리면 대상 상품만 골라 플랫폼별 고지 엑셀 생성
- NESS, NBOX, 숲토어 각각의 양식에 맞춘 고지 멘트 생성
- 파일은 브라우저 안에서만 처리하고 어디에도 업로드하지 않음

## 사용법

1. 웹 주소 `https://dklim-ship-it.github.io/pumdanbok-notice/` 를 크롬으로 엽니다(북마크바 등록 권장). 어느 PC에서나 같은 주소로 열립니다.
2. 받은 공지 텍스트를 붙여 넣습니다.
3. NESS, NBOX 상품 파일을 올립니다.
4. 플랫폼별 멘트를 복사하고 고지 엑셀을 저장합니다.

엑셀 처리 라이브러리를 불러오느라 인터넷 연결이 필요합니다.
